# statistical-matching-ukraine

Part of my Master's thesis work where different statistical matching methods were tested on Microcensus data from the Federal Office of Statistics (Destatis) in Germany.  In brief, the foreigner register was used to train a prediction model, which was then applied on the microcensus to predict whether someone was a refugee seeker.  Worked in conjunction with Destatis, whose teams have vested interest in this topic.  Note that only the code is available - all data sources used was confedential.

For more details, see "Estimating labour force participation of refugees by statistical matching of administrative and survey data" by Jan Eberle and Marieke Smilde-Becker.
